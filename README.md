# 칼데아 기록 보관소

TRPG 「포켓몬 그랜드 오더」의 공개 기록 사이트입니다.
**사이트:** https://engell00-cmd.github.io/chaldea-archive/

- **칼데아스 관측실** (`index.html`) — 특이점 지도. 지구본을 돌리고 특이점을 고르면 관련 기록으로 레이시프트합니다.
- **기록 보관소** (`archive.html`) — 세션 로그 목록과 검색.
- **마슈의 인물 관계도** (`board.html`) — 코르크보드식 관계도.
- **완결 사건 파일** (`archive-<id>.html` · `board-<id>.html`) — 끝난 특이점의 기록과 사건 관계도. 지금은 세라픽스(`seraphix`). 어떤 로그가 들어가는지는 `catalog.json` 의 `cases`, 사건 관계도 인물·좌표는 `relations.json` 의 `cases`.

## 로그 올리는 법 (GM)

1. 정리된 로그 HTML(「로그 이미지 부여」판)을 준비합니다. **PL에게 보여도 되는 판(가림판)만** 올립니다.
2. 이 저장소의 `logs/` 폴더 → **Add file → Upload files** → 파일을 끌어다 놓고 **Commit changes**.
3. 1~2분 뒤 사이트에 자동으로 반영됩니다. (Actions 탭에서 진행 상황 확인)

- 테마, 미니 관계도, 등장인물 토큰은 로그에서 자동으로 만들어집니다.
- 파일 이름에 `원본`, `(GM)`, `GM용`, `GM 전용` 이 들어가면 **올라가도 사이트에 싣지 않습니다.** (그래도 저장소에는 공개되니 애초에 올리지 마세요.)
- 분류 규칙은 `data/catalog.json` 에서 바꿉니다.

## 데이터 (`data/`)

| 파일 | 내용 |
|---|---|
| `atlas.json` | 관측실 특이점. 공개된 특이점만 내용이 있고, 나머지는 `redacted` 가림막 |
| `relations.json` | 관계도 인물·관계 (PL 공개분, 가림막 포함) |
| `tokens.json` | 관계도 카드 이미지 |
| `catalog.json` | 로그 분류·특이점 연결 규칙 |
| `scenes.json` | 장면별 배경 이미지·지구본 좌표 |

⚠ **이 저장소는 공개입니다.** GM 전용 설정은 여기에 두지 않습니다. GM판 원본은 GM의 컴퓨터에만 있습니다.
